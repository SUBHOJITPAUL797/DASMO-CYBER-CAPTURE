WHATSAPP DESKTOP SETUP GUIDE
1. Click "Start Virtual Cam" on the dashboard.
2. Open WhatsApp Desktop > Settings > Audio & Video.
3. Under Camera, select "DASMO CYBER CAPTURE".
4. Under Microphone, select "CABLE Output (VB-Audio Virtual Cable)".
5. In Windows Settings > System > Sound > Volume mixer, select "CABLE Input" as Output device to route PC sound to phone speaker.
